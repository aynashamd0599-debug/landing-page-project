# مشروع صفحة الهبوط (Landing Page)

## نبذة عن المشروع
تم تصميم وبرمجة هذه الصفحة كجزء من متطلبات مساق **تصميم وإدارة مواقع الإنترنت**. تعرض الصفحة تصميم هبوط بسيط يتضمن صورة جبال ثلجية بتنسيق متجاوب وأكواد HTML وCSS منظمة وموثقة بالتعليقات.

## محتويات المستودع (Repository)
- `index.html`: الصفحة الرئيسية التي تحتوي على هيكل وتصميم موقع الويب.
- `landing.jpg`: صورة العرض المستخدمة في الصفحة.
- `README.md`: ملف التوضيح والتوثيق للمشروع.
